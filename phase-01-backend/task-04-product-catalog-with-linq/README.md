# Task 04 - Product Catalog with LINQ

## Overview

This project is a console-based Product Catalog application built using C# and LINQ.

The main goal of this task is to practice LINQ queries for filtering, sorting, grouping, searching, reporting, projection, and pagination.

The project contains a fixed dataset of 25 products provided by TechMaster Academy.

---

## Technologies Used

- C#
- .NET
- LINQ
- Console Application
